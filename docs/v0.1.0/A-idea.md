# bloatware v0.1.0

As a perfectionist, I often find myself spending days designing "good" software
in my head, while struggling to concentrate during implementation phase.
The idea behind initial release of the project bloatware was to force myself out
of this loop and get a "good-enough" site up and running.

The current (as of July 13, 2026) codebase was written entirely using Monkey
Prompting - a term I use for code generated using (so called) AI coding tools.
It works. But my little brain cannot live with it.

The primary objective of v0.1.0 is to move from "make it work" to "make it reliable".
The idea is to follow formal software development workflow, think how to write
maintainable code, have proper documentation, testing suite and incorporate
secure practices (?) and (maybe) learn more about compliance and accessibility.
